How to Use

Create the review link

  1. Find the business in Google Maps and check its address.
  2. Tap Share, then Copy link.
  3. Paste that link into Chrome and open it.
  4. Copy the expanded google.com/maps URL from Chrome's address bar.
  5. Paste the expanded URL below.
Open Google Maps

Save and publish

  1. Copy the review link above.
  2. Open Admin and choose the card number.
  3. Paste the review link and tap Save Locally.
  4. Tap Test and confirm the correct business opens.
  5. Tap Copy JSON.
  6. Tap Update GitHub.
  7. Replace all the file contents, then tap Commit changes.
  8. Wait a few minutes and scan the NFC card.
Open Admin Open NFC Setup

Save Locally does not update the live card. The card changes only after redirects.json is committed to GitHub and Pages finishes deploying.
