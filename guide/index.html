How to Use

Fastest workflow

  1. Open Google Maps and find the exact business.
  2. Check the address, phone number, and photos.
  3. Tap Share, then Copy link.
  4. Copy the request below and send it with the Maps link.
  5. Wait for the card update to be deployed, then test the permanent NFC URL.
Open Google Maps

Do it yourself

  1. Paste the Maps share link into Chrome and open it.
  2. After the listing loads, copy the expanded google.com/maps URL from Chrome's address bar.
  3. Paste that expanded URL into the builder below.
  4. Copy the generated review link.
  5. Open Admin, choose a card, paste the link, and select Save Locally.
  6. Select Test. Confirm the correct business name appears.
  7. Download redirects.json and replace the file on GitHub.
