How to Use

Set a card from your phone

  1. Find the business in Google Maps and check its address.
  2. Tap Share, then Copy link.
  3. Tap Set Card from Maps Link below.
  4. Sign in to GitHub if asked.
  5. Tap Run workflow.
  6. Enter the card number, such as 03.
  7. Paste the short Google Maps link.
  8. Tap the green Run workflow button.
  9. Wait a few minutes, then scan the NFC card.
Open Google Maps Set Card from Maps Link

The copied maps.app.goo.gl short link is correct. You do not need to expand it.

If you already have a direct review link

  1. Open Admin and choose the card number.
  2. Paste the review link and tap Save Locally.
  3. Tap Test and confirm the correct business opens.
  4. Tap Copy JSON.
  5. Tap Update GitHub.
  6. Replace all the file contents, then tap Commit changes.
  7. Wait a few minutes, then scan the NFC card.
Open Admin Open NFC Setup

Save Locally does not update the live card. The card changes after redirects.json is committed to GitHub and Pages finishes deploying.
