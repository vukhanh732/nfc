NFC Card Setup

Program each card once with its permanent URL.

Android NFC Tools

  1. Open NFC Tools
  2. Go to Write
  3. Add a URL/URI record
  4. Paste the card URL
  5. Tap Write
  6. Hold the phone against the NFC card
  7. Label the physical card with the same number

Do not make the NFC tag read-only until everything has been fully tested.
